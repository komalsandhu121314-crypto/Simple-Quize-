Project Description

The Simple Quiz System is a basic web-based application developed using PHP. It allows users to answer quiz questions and check their answers.

Objective

The main objective of this project is to create a simple quiz application and understand PHP programming concepts.

Features

- Displays quiz questions.
- Provides multiple-choice answers.
- Accepts user answers.
- Processes answers using PHP.
- Displays quiz results.

Technologies Used

- HTML
- PHP
- CSS

Concepts Used

- PHP Variables
- Arrays
- Functions
- Conditional Statements
- Form Handling
- POST Method

Steps to Run

1. Install XAMPP.
2. Copy the project folder into the "htdocs" directory.
3. Start Apache server.
4. Open your browser.
5. Enter "http://localhost/project-folder/".

Conclusion

This project helps beginners understand PHP fundamentals, form handling, arrays, and conditional statements through a simple quiz application.# Simple-Quize-
